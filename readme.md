# Standardization Code
This file contains a summary of the agreements on standardisation and the way in which we will carry out the standardisation process. Future changes or suggestions to this file and the folder we created will be reviewed with the team beforehand.
## Folder Structure
* ***Index*** is the only HTML file outside the ***modules*** folder.
* When we are going to upload the project we have to **delete** the following folders/files:
    * `node modules`
    * `src`
    * `readme.md`
## CSS
**global.css**
* All the colors of the project will be within the `root`.
* The variable name of each color will be with light or dark depending on the shade (`——LightBlue1: #4a44f9`).
* **Fonts** and **fonts classes** are variable depending on the project.
**main.css**
* Inside this file we are going to import the global.css and the other css files that are created inside the project.
## JS
* We will generate different JavaScript files depending on each project taking into account the number of pages, the difficulty of the functions or the amount of information.
## Comments
* All **comments** must be in **english**.
* We will use the **Comment Anchors** extension to comment the code, separate sections and describe functionalities.
